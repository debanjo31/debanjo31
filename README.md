**Key technologies**

`AWS CDK` · `TypeScript` · `CloudFront` · `S3` · `CodePipeline` · `Step Functions`

**Highlights**

* Blue/green deployment architecture
* CloudFront continuous deployment
* Automated build and deployment pipeline
* Manual validation before production promotion
* Atomic environment promotion
* Automated CloudFront cache invalidation
* Infrastructure fully defined as code
